API 키 넣기

이 앱은 서버 없이 브라우저에서만 돌아가요. 키는 이 브라우저에만 저장되고, Google과 Deepgram에 직접 보내져요. 공용 컴퓨터에서는 다 쓴 뒤 “키 지우기”를 누르세요.

Gemini 무료 등급은 사용 한도가 있고, 보낸 내용(이력서 포함)을 Google이 서비스 개선에 쓸 수 있어요. 전화번호·주소 같은 개인정보는 지우고 올리세요.

읽어 주는 목소리

“듣기”와 면접관 질문을 읽어 주는 목소리예요. Gemini 목소리는 사람처럼 자연스럽지만 무료 사용량을 조금 써요. 같은 문장은 한 번만 만들어서 다시 쓰고 있어요.
